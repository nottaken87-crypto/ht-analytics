Terms of Service — Hollow Terrors Analytics

Last updated: November 7, 2026

Hollow Terrors Analytics is a private, single-purpose tool operated by the owner of the TikTok account @hollowterrorschannel. It is used only by that account's owner to read analytics for that account's own videos through TikTok's official Display API.

Use of the tool

The tool may be used solely to retrieve view counts and basic profile information for the @hollowterrorschannel account, for the channel owner's own reporting and content planning. It is not offered to the public, has no other users, and does not post, modify, or delete any content.

Data

The tool accesses only data made available through TikTok's Display API under the scopes the account owner grants (user.info.basic and video.list). Access can be revoked by the account owner at any time in TikTok's settings, which immediately ends the tool's access.

The tool is provided as is, for the account owner's internal use only.
